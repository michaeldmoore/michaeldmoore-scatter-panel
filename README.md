# Scatter

A Grafana panel plugin that displays its name in a read-only text box. This is the starting point for the scatter panel implementation.

## Development

- `npm run dev` builds the plugin in watch mode.
- `npm run build` creates a production build in `dist`.
- `npm run lint` checks the project with Grafana's ESLint configuration.
- `npm run typecheck` checks the TypeScript sources.

Run the plugin in Grafana with `docker compose up`.
